# EduTalks AI Pronunciation Frontend

This project is the frontend for EduTalks’ AI-based pronunciation learning platform.  
It connects to the EduTalks backend API for authentication, lesson data, and pronunciation scoring.

## Features
- User registration and login
- Dashboard with pronunciation exercises
- AI pronunciation feedback

## Tech Stack
- React + Vite
- Tailwind CSS
- shadcn/ui
- Axios for API calls

## Getting Started
1. Clone the repo
2. Run `npm install`
3. Set up your `.env` file with backend URLs
4. Run `npm run dev`
